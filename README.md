# Healthcare Analysis Project

## 📌 Project Overview

The Healthcare Analysis Project is an end-to-end data analytics project focused on analyzing healthcare data to identify meaningful patterns, trends, and insights related to patients and diseases.

The project uses Python, SQL, Tableau, and Streamlit to perform data cleaning, analysis, visualization, and interactive reporting.

## 🎯 Project Objectives

* Analyze healthcare and patient data.
* Perform data cleaning and preprocessing.
* Identify important patterns and trends.
* Conduct patient and disease analysis.
* Perform SQL-based data analysis.
* Build interactive dashboards using Tableau.
* Develop a user-friendly Streamlit application.
* Generate meaningful healthcare insights for better decision-making.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* SQL
* Streamlit
* Tableau
* Jupyter Notebook

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone <repository-url>
cd Healthcare-Analysis-Project
```

### 2. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit Application

```bash
streamlit run 05_streamlit/app.py
```
